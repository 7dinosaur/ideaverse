### 要点：
- **研究问题**：第二代超音速商用运输机（SCT）要商业可行须同时满足性能、噪声、经济性等跨学科强耦合目标，要在概念设计阶段有工具自动找出满足全套约束的最优构型与技术组合；用 ASTRO 代码做两项研究：①噪声限值严于 FAR36 Stage 3 时的设计代价（MTF 变循环发动机对象）；②亚音速航段占比对最优构型的影响
- **解决方法**：ASTRO = 模块化 SCT 设计综合程序（几何/质量/阻力/任务/噪声/低速性能）+ RQPMIN 约束非线性优化器；最多 33 独立变量、29 约束，目标可选起飞质量/DOC/COC。噪声研究：优化出 Stage 3 基准构型→逐条加严边线/飞越/进场限值重新优化得敏感性曲线，另试 4° 下滑角；亚音速研究：总航程 5700 nm 固定，亚音速段（M0.95）占比 0→90% 扫描，双任务分别覆盖段在前/在后
- **局限性**：无平尾/鸭翼、垂尾无尺寸驱动力模型（研究中固定）；质量全用协和经验简化公式（机翼式对屈曲板理论平均误差 2%，仅验于 650–930 m²、AR 1.7–2.6）；波阻 BAe 法仅有限构型精度可接受；升致阻力数据仅覆盖 AR 1.7–2.6（亚音速研究 60% 占比处 AR 顶到上限）；噪声仅算喷流噪声（无涡轮机械/机体噪声）；高升力配平与操纵功率需求未建模；最多两个任务；结论绑定于给定技术假设（MTF 固定循环、起飞喷流速度 400 m/s 等），且为初步研究
- **全文脉络**：引言（SCT 挑战 + DERA/BAe 合作背景）→ RQPMIN 数学描述 + 独立变量表/约束与目标表 → ASTRO 建模（几何→质量→阻力→任务→噪声，含减噪 bunt 与 cutback 高度）→ 噪声限值敏感性（基准：进场为唯一 active 约束 +2.0 EPNdB；边线/飞越各可承受 −3.0 EPNdB 且靠 cutback 高度 1:1 互易；进场仅 −0.35 EPNdB；4° 下滑角 +3.0 EPNdB）→ 亚音速航段研究（AR +35%、燃油在 40% 占比处先升后降、>50% 丧失全超音速航程、DOC 目标→更大 AR 更小发动机）→ 结论

**方法提炼（只列）：**
- 约束非线性优化：min f(x)，s.t. x_iL ≤ x_i ≤ x_iU；C_j(x)=0 / C_j(x)≤0 / a_j ≤ C_j(x) ≤ b_j（RQPMIN；变量与约束清单见 Table 1、Table 2）
- 目标函数三选一：起飞质量、直接使用成本 DOC（现金成本+持有财务成本）、现金使用成本 COC（飞行+维护成本）
- 摩擦阻力：Σ（部件湿面积 × 均匀粗糙度平板湍流摩阻系数 × 形状因子 × 技术因子）
- 波阻（Raymer）：D ∝ (S_max/L_fus)²；波阻（BAe）：几何参数法 + 发动机安装因子
- 面积律（area-ruling）：机身宽度局部收缩控制 S_max
- 亚音速升致阻力：BAe SCT 气动数据数组插值（含襟翼偏转修正）；超音速升致阻力：基于平面形状的 BAe 表达式（拟合线性化理论结果）
- 质量估算：BAe 协和经验公式；机翼质量与屈曲板理论方法对比校核
- 任务建模：爬升-巡航段（cruise-climb legs），段长自动修正补偿变高变速油耗；各段起始高度为独立变量
- 爬升性能 ∝ (T−D)/W；巡航高度调定约维持恒定 C_L；比航程比较
- 喷流噪声：BAe 预测法（协和 Olympus 实测修正），输入推力/喷流速度/喷流压比/高度；指标 EPNdB
- Stage 3 限值规则 → 5 个噪声约束：单条超限 ≤ +2 EPNdB、三余量和 ≤ 0、正超限和 ≤ 3 EPNdB
- 声压级反平方高度衰减（4° 下滑角 = 2.2 高度收益 + 0.8 推力收益 = 3.0 EPNdB）
- 发动机数据按推力缩放因子缩放；短舱横截面积计算扣减圆形流管

## 总结：
**工程应用型文章：核心贡献是把 SCT 跨学科概念设计综合与约束多变量优化打包成 ASTRO 工具，并把机场噪声（喷流噪声）拉进概念设计回路直接驱动优化；数学关键在于"综合模型出约束与目标、RQPMIN 出搜索"的解耦架构——同一代码切换目标函数与约束组合即可覆盖噪声敏感性、任务剖面、经济性等多类研究。工程 insight：SCT 噪声瓶颈在进场（余量近零）；边线/飞越噪声可靠 cutback 高度按约 1:1 EPNdB 互易；亚音速航段显著推高展弦比需求（+35%），40% 占比处出现燃油峰值；以 DOC 为目标得到更大展弦比、更小发动机与更低油耗**
