# 总体设计中动力系统参数估算方法调研

## 一、发动机数据获取的三条技术路线

飞机总体设计中,发动机特性(推力/油耗的"高度—速度—油门"三维数据表)、质量、特征尺寸是必需数据。获取途径分三类(Raymer Ch.6 与南航学报综述划分一致):

| 路线 | 适用阶段 | 特点 |
|------|---------|------|
| ① 相近推力已有发动机数据 | 初始概念设计 | 直接查统计表,只在推力范围内有效 |
| ② 橡皮发动机(Rubber Engine)缩放 | 概念设计迭代 | 基准发动机按比例因子缩放,快速但外推有限 |
| ③ 循环参数分析模型(Parametric Deck) | 全过程 | 基于 BPR、OPR、比推力、涡轮前温度 T4 四个总体循环参数,可做选型与参数扫描 |

核心参考:
- **Mattingly《Aircraft Engine Design》(AIAA, 3rd ed.)** — 完整流程:约束分析 → 任务分析 → 参数循环分析(设计点)→ 性能分析(非设计点)→ 装机性能,配套 AEDsys/ONX/NEPP 软件。配套论文 AIAA 1989-2260 (https://doi.org/10.2514/6.1989-2260) 给出双转子混排加力涡扇的推力衰减方程,直接把装机损失写进衰减模型。
- **Häßy & Fröhler, AIAA 2023-4304**(虚拟推进专家)— rubber engine 进化版:代理模型 + 表格化非设计点性能图,含 snowball effect 分析。

## 二、推力估算

**1. 约束分析定 T/W**(Raymer Ch.5 / Mattingly Ch.2):由起飞滑跑、爬升梯度、巡航/盘旋、机动等需求在 W/S–T/W 图上找包线,最初确定发动机规模的正统方法。

**2. 缩放法**:`F_inst = SF · F_base(M, h, 油门)`,SF 为缩放因子;发动机质量、直径、长度按推力比例同步缩放(Hammami/Scholz 718 台发动机回归:质量、风扇直径、长度近似正比于起飞推力)。

**3. 推力衰减(Lapse)模型**:
- 通用特性处理:推力和油耗对 (θ, δ) 无量纲化,用 **F/(δF₀) ↔ TSFC/√θ 回归曲线**覆盖全包线;
- 比推力修正:低比推力(高涵道比)发动机推力随速度衰减更快,统计式需按 BPR/比推力修正。

**4. 装机修正(Installed Thrust)** — 装机净推力 = 未装机净推力 − 进气道阻力 − 尾喷管/船尾阻力,未装机推力还要扣除引气与功率提取:

```
F_installed = F_gross − F_ram − D_inlet − D_afterbody  (扣除 customer bleed / off-take)
```

- **进气道总压恢复**:M<1 取 1.0;M>1 按军用规范 **MIL-E-5008B: η_R = 1 − 0.1(M−1)^1.35**(AIA 标准为 1 − 0.075(M−1)^1.35),NASA GRC Inlet Performance 页有现成公式:https://www.grc.nasa.gov/www/k-12/BGP/inleth.html ;实际进气道一般低于标准值。
- **阻力分量**:溢流阻力(additive/spillage)、附面层抽吸阻力、旁路阻力、船尾/喷管干扰阻力。
- 经典体系文献:
	- **Ball, PITAP 系列**(https://apps.dtic.mil/sti/pdfs/AD0907817.pdf ):推阻簿记 + 进气道数据目录;AIAA 1976 (https://doi.org/10.2514/3.58685) 给出快速计算流程;
	- **NASA TM(1976)**:600 行 FORTRAN 简化装机损失法,覆盖宽马赫数范围,专为概念设计程序开发:https://ntrs.nasa.gov/api/citations/19770009073/downloads/19770009073.pdf
	- **Stauffer, AIAA SciTech 2023**:推阻簿记历史综述,讨论各种"看似对、实际错"的推力定义组合——做 MDO 耦合前值得读一遍防坑。
- **量级参考(超声速)**:下一代超声速公务机研究(Aeolus E19, 2025)给出**超声速段进气道阻力占装机净推力 8.8%~14.2%**,可变旁路进气控制可再省 0.8% 装机 SFC:https://doi.org/10.3390/engproc2025090050

## 三、燃油(油耗)估算

**1. TSFC 统计相关式**(给不出循环参数时):
- **线性速度模型**:`TSFC = c_a·V + c_b`,c_a、c_b 由 BPR 回归(718 台发动机数据,HAW Hamburg Scholz 团队,https://www.fzt.haw-hamburg.de/pers/Scholz/arbeiten/TextHammami.pdf );对低巡航马赫数外推尤其重要;
- **南航学报模型**(《面向客机总体设计的涡扇发动机分析模型》,https://jnuaa.nuaa.edu.cn/html/2016/3/201603014.htm ),公式齐全可直接抄:
	- 理想效率下 `TSFC ≈ 0.25·Ma`;
	- 非设计点:`C = C_OD·(1−0.15·BPR^0.65)·[1+0.28(1+0.063·BPR²)·Ma]·σ^0.08`
	- `C_OD = C₀·[1+0.01(T_c/T_OD − 1)]`(已含装机与引气的保守影响);
- Raymer 教材 TSFC 统计表(按发动机类型/年代),配合 jet-engine.net 民用涡喷/涡扇开源数据库(含 Excel 版)交叉验证。

**2. 任务燃油两条路**:
- **燃油系数法(Fuel Fraction)**:`W_f/W_0 = 1.06·Π(W_{i+1}/W_i)`,各段用 Breguet 方程——喷气巡航段 `R = (V/TSFC)·(L/D)·ln(W_i/W_f)`。快,适合第一轮初估(Raymer Ch.6);MATLAB 现成工具 https://www.mathworks.com/matlabcentral/fileexchange/38973-fuel-fraction-sizing
- **任务剖面积分法**:用发动机 deck 沿任务数值积分,fixed-engine sizing 用它做收敛迭代;总重收敛时注意**雪球效应**(发动机增重→推力需求变化→燃油变化循环耦合,Häßy 2023 有专门讨论)。

## 五、应用建议(低声爆超声速飞行器 MDO 背景)

与 [[+/Li Wu——考虑任务约束的低声爆超声速飞行器多学科设计优化(BCO方法文献)|Li Wu MDO 文献]] 衔接(其中已涉及推力耦合):
1. **快速迭代层**:南航模型或 Raymer 统计式 + MIL-E-5008B 恢复修正,响应快,适合外层优化循环;
2. **精度层**:pyCycle 建低涵道比/变循环 deck + Aeolus E19 式超声速进气道装机修正(量级:超声速段 inlet drag ≈ 10% 装机推力,不可忽略);
3. **推阻簿记先定标准再耦合**,否则 CFD 气动数据和 deck 推力容易重复计阻力(Stauffer 2023 的教训)。
