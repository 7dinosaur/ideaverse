1、低声爆与高经济存在矛盾 -> 飞行策略规避 -> 常规飞行剖面不满足设计需求（航程、重量虚标） -> 一种在设计初期针对任务场景精确估算可用航程与起飞总重的超声速民机设计方法。
2、SST航线分类（简化航线） -> 大部分现有航线存在不连续的海上航段（N条航线的超巡航段对比） -> 需要针对超声速民机计算航线 -> 提出一种航线优化方法 -> 分析优化结果 -> 少量航程代价换取连续超巡
3、航线给出总航程与声爆约束，但是不知道最优飞行剖面 ->  重量-剖面联合迭代方法 -> 对比总重 -> 能够降低设计最大总重
4、多任务点低声爆设计
给定可用于最远航程的最大起飞重量 -> 空重 -> 不同航线固定空重下（可能不满油）巡航点的重量才是低声爆设计用到的飞行重量（巡航段声爆是持续下降的） -> LSG方法说明不同重量的低声爆目标不同 -> 给出新的设计模式：远航程满油，飞行策略规避低声爆限制，近航程不满油，重量轻可以低声爆飞行
