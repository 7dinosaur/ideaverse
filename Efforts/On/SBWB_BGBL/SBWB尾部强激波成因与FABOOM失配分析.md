# SBWB尾部强激波成因与FABOOM失配分析

关联：[[SBWB后体特性分析]]、[[FABOOM]]

> [!abstract] 问题定义
> CFD显示优化后外形尾部存在强激波（H/L=0.5时Δp/p≈0.064），但[[FABOOM]]（PanAir面元法+修正线化理论）几乎无法捕捉。需要回答两个问题：
> 1. 这道激波的空气动力学成因是什么？
> 2. 为什么修正线化理论体系算不出来？

> [!success] 已确认事实（2026-09-02）
> 1. **缺失在源头**：FABOOM在0.5L处（传播起始平面）的签名就不含尾激波尖峰 → 排除传播数值问题（P层全部排除）。
> 2. **无粘机制**：欧拉方程同样算出该激波 → 排除黏性/边界层排移/分离机制（S4排除）。
> 3. **HL定义确认**：HL=飞机下方N倍体长处的提取平面 → 幂律是传播衰减。拟合指数≈0.8，接近体积型弱激波渐近r^(−3/4)，远于升力尾激波r^(−1/2)（建议补H/L=4~6确认渐近趋势）。

> [!important] 当前诊断（收窄后）
> **激波是无粘、贴体、由后体局部几何驱动的再压缩激波**：
> 后体肩部强膨胀（局部、无粘，dp/p≈−0.1）→ 闭合处流动必须再压缩回环境/尾迹压力 → 膨胀深+当地Ma高+凹转折集中 → 压缩波在离体远小于0.5L处聚并成激波 → 强度≈过膨胀深度，随距离按弱激波规律衰减。
>
> FABOOM源F缺失它的原因只剩两个嫌疑：
> - **框架固有限制**（主嫌疑）：①等效截面积把激波强度绑定在dA/dx上，而真实强度由局部过膨胀深度决定；②Ma平面切割把中心线局部特征在展向/斜切方向抹平；③0.5L近场仍处"局部几何主导"区，等效旋成体的远场等效性尚未建立。旁证：签名前段（鼻激波、中段）FABOOM与CFD吻合良好，唯独尾部失效——正是"局部有效性破坏"的表现形态。
> - **工具缺陷**（待排除）：A_e尾部构造、离散、切割定义的具体错误。
>
> **判别方法**：导出FABOOM内部实际使用的A_v(x)、A_L(x)、F(x)尾部曲线，与从CAD独立重算的Ma平面A_e对比。一致且光滑→框架限制；不一致→工具bug。

## 第一部分：强激波成因假设树（更新状态）

### M1 过膨胀—再压缩机制（主嫌疑，获两条独立支持）
- 后体肩部强膨胀（云图dp/p≈−0.1）→ 闭合处再压缩 → 激波。
- 关键认识：**激波强度由过膨胀深度决定，而不是直接由dA_v/dx决定**。截面积闭合速率是展向平均量，膨胀深度是局部中心线流动量——宽扁机身中心线下表面的局部转折角/曲率可以远大于平均面积所暗示的。这是"体积变化不快却有强激波"的核心出路。
- 深层膨胀的候选来源（待细分）：①后体下表面当地转折角/曲率；②三维横流（绕宽扁机身肩部类似绕钝前缘，等效旋成体概念中无对应物）；③机翼对后体流场的加速（"无机翼干扰"目前只基于衰减行为，形成机制未验证）。
- 定量核对：物面p_min按再压缩压比估算激波强度，与实测跳变（0.5L处0.064）对比量级。

### M2 底部/尾迹低压机制（变体待查）
- 黏性排除后仅剩"Euler中的钝底死区"变体。查几何尾部是否收口成尖点即可排除/确认。

### M3 升力终止（Kutta jump）机制（弱化）
- 指数0.8不支持（升力尾激波应为r^(−1/2)）。可用展向扫描+FABOOM的A_L尾跳定量排除。

### M4 纯远场非线性聚并（已排除）
- 试验1证明源头缺失+激波贴体；且等面积律下传播不能放大——若FABOOM尾部F仅~0.02量级，任何传播都变不出0.064。

- [x] 试验1：FABOOM 0.5L源平面对比 → 缺失在源头
- [x] Euler验证 → 无粘机制

- [ ] 展向扫描：尾部多展向站位签名（中心线集中→局部体机制；均匀→面积律型）

## 第二部分：FABOOM失灵故障树（更新状态）

> [!important] 核心逻辑
> 弱激波/等面积律框架内，**传播只能重排源F函数的已有结构，不能放大激波强度**。试验1已确认源头缺失，此逻辑成为终局结论。

- ~~P 传播层面~~：已排除（试验1）。
- ~~S4 黏性/BL排移~~：已排除（Euler复现）。
- S1 小扰动假设失效 + S2 PanAir无激波本质 + S3 平均化稀释：合并为"框架固有限制"主嫌疑。
- S3中的定义/离散错误：待"FABOOM内部A_e导出对比"判别。

## 逻辑缺口提醒（已部分解除）

> [!warning]
> 原推理"FABOOM捕捉不到 ⇒ 不是体积快速变化引起的"曾有三条逃逸路径：小扰动失效、黏性、A_e定义。现黏性已被Euler排除；剩下"小扰动失效"恰是框架限制主嫌疑的核心内容；"A_e定义"待判别实验。当前可安全表述为：
> **"该激波强度不由截面积闭合速率控制，而由局部过膨胀深度控制（待形状族相关性最终确认）；修正线化理论的源F不含这一局部机制。"**

## 行动出口

1. **工作流（推荐）**：这类后体的声爆评估改用"CFD近场（0.5~1L）提取 + FABOOM传播"的混合流程（现代低声爆流程的标准做法）；线化理论（JSGD）用于方案方向探索，尾部以CFD为准。
2. **设计准则（由M1直接导出）**：激波强度≈过膨胀深度 → 用**物面p_min做快速判据**：|p_min−p∞|/p∞ < 目标激波强度。不必等远场传播即可筛选外形。
3. 工具层面打补丁（不推荐，成本>收益）：把局部膨胀-再压缩作为修正F叠加进线化体系。
